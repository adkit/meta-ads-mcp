# Privacy

The Meta Ads MCP server is run by AdKit. It connects only to the Meta Ads accounts you authorize.

To do what you ask, it reads and changes ad account data: campaign settings, creatives and performance metrics. Requests go through AdKit's server at https://mcp.adkit.so.

Your Meta Ads sign-in is handled by Meta Ads's own OAuth flow. AdKit stores the account identifiers, drafts and operation records it needs to run the service.

Full privacy policy: https://adkit.so/legal/privacy

Contact: contact@adkit.so
